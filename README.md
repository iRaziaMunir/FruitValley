# 🍎🥕 FruitValley - Fresh Fruits & Vegetables Online Store

A modern, responsive e-commerce web application built with React for purchasing fresh fruits and vegetables online. FruitValley provides a seamless shopping experience with an intuitive interface for browsing and ordering fresh produce.

## 🚀 Features

- **Browse Products**: View all available fruits and vegetables
- **Product Categories**: Filter products by category (Fruits, Vegetables)
- **Product Details**: View detailed information about each product
- **Shopping Cart**: Add/remove items and update quantities
- **Search Products**: Search for specific fruits and vegetables
- **Responsive Design**: Works on desktop, tablet, and mobile

## 🛠️ Built With

- React.js
- React Router for navigation
- Redux for state management
- CSS Modules/Tailwind CSS for styling
